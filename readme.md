# linux network & server toolkit

## about
a beginner-friendly linux project

 ## features
 - network connectivity check
 - dns resolution check
 - ip and gateway information
 - nginx server monitoring
 - port monitaring
 - website http response check
 - bash automation
 - cron scheduling
 - log and report generation
 
 ## technologies
 - ubuntu linux
 - bash scripting
 - networking
 - nginx
 - git and github
 - cron
 
 ## how to run
 
 run network check:
 ./spt/network_check.sh

 run server check:
 ./spt/server_check.sh
